# 30+ 数据图表工具箱 · 更新说明

**版本：2026-09-24（最新发布版）**

一个可以装进单个 HTML 文件里的「数据图表工具箱」：**30 张现成图表 · 8 个用途分组 · 20 款设计风格 · 一键复制提示词**——断网可用，无需安装，双击就能打开。

---

## ✨ 本版更新亮点

**1. 开头栏目「精修」**
- 眉标前置品牌圆点，整体节奏与间距收顺
- 品牌渐变条收细（3px → 2px）
- 副标题行宽收拢，阅读更舒适
- 「关于数据」说明由整条横幅改为单行提示胶囊

**2. 图鉴 × 创作台 头部完全同规**
- 两个工作区统一为同一套头部骨架：眉标 → 大号 30⁺ → 主标 + 徽章框 → 彩色横条 → 副标
- 「30+」上标加号、主标字号、徽章尺寸与图鉴逐像素一致，切换时视觉无缝呼应
- 「Studio」英文收进徽章框，与 SE / Plus / Pro 徽章同规格

**3. 创作台（Studio）**
- 20 款设计风格一键换装（5 大流派 × 4 款）：版面底色、字体、图表造型与提示词同步改写
- 6 套色系自由切换，30 张图表同步变色
- 1280 × 720 汇报版式，每批 12 页，支持「换一批组合」
- 一键复制提示词（完整档 / 精简档）、打印 / 导出 PDF、放大查看（附该页提示词全文）
- 「夜航」配色主题：深空紫 + 流光绿，网格底纹与颗粒质感

**4. 单文件四档视图（完整版）**
- 「SE / Plus / Pro / Studio」四档视图合并于同一个 HTML 文件：顶部吸顶条一键切换，自动记住上次选择
- Studio 与三档模式平级，不再分「图鉴 / 创作台」两套切换逻辑
- 切换与视觉精修：四段指示丸滑动、视图切换柔和过渡；顶栏圆角、页面宽度与三档视图完全统一
- 「Pro 完整」更名为「Pro 专业」；吸顶栏毛玻璃更通透

## 🚀 怎么用

1. **双击打开**任一 HTML 文件（Chrome / Edge / Safari 均可；无需联网、无需安装）
2. **图鉴**：挑一张图 → 对照「要交给我的数据」备好数据 → 点「一键复制」，把代码连同数据文件发给 AI
3. **创作台**：挑风格 → 挑版面 →「复制提示词」→ 连同数据 / 图本发给 AI
