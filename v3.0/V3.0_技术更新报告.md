## 1 概述

### 1.1 编制目的

本报告记录「50+ 数据图表工具箱」2.0 版至 3.0 版的全部变更内容、技术实现方式、核验结论与遗留事项，作为该版本的技术归档文件，同时可作为对外发布说明的底稿。

### 1.2 适用范围

本报告适用于 3.0 版交付的三个单文件 HTML 产物。该系列产物的基本形态为：将图表引擎、样式表与脚本全部内联于单个 HTML 文件，不依赖任何外部资源，可在断网环境下直接打开使用。

### 1.3 术语与约定

| 术语 | 含义 |
| --- | --- |
| 图表编号（n） | 图表在页面中的固定序号，1–50，与 2.0 版前 30 张的编号完全延续 |
| 用途分组 | 按使用意图对图表进行的归类，共 11 组，由源码常量 `GRP` 定义 |
| 吸顶条 | 页面顶部随滚动固定的导航条 |
| 补位 | 双列版式下，分组末尾卡片跨占两列以消除右侧空缺的处理 |
| 色系 | 可整体切换的配色方案，共 6 套，作用于全部图表 |
| 断点 | 媒体查询切换阈值，本版使用 400px / 760px / 1200px / 1600px 四级 |

### 3.3 移动端适配

2.0 版未包含任何移动端处理，在窄屏设备上存在横向溢出、顶部导航挤压、创作台头部吸顶遮挡等问题。本次新增三段样式补丁（`resp-v1` 至 `resp-v3`），均追加于 `</head>` 之前、位于全部既有样式之后，依靠「相同特异性下后者生效」的规则覆盖，未修改任何原有规则。

| 序号 | 变更项 | 技术实现 |
| --- | --- | --- |
| 1 | 760px 断点 | 沿用既有 8 级字型变量体系整体下调一档，调整范围限于变量定义；卡片容器改为单列 |
| 2 | 400px 断点 | 进一步收缩页面内边距，主标题字号降至 36px，切换按钮尺寸压缩 |
| 3 | 顶部吸顶导航 | 允许换行；分区切换条改为整行横向滚动（隐藏滚动条并启用惯性滚动） |
| 4 | 创作台头部 | 原 `sticky` 定位在窄屏下折行后高度达 760px 以上，遮挡视口约 104%；窄屏改为普通文档流，仅保留顶部导航吸顶 |
| 5 | 横向溢出 | 图鉴吸顶条的通栏负边距在窄屏归零，消除 2px 级溢出 |
| 6 | 触屏可点性 | `pointer: coarse` 媒体查询下增大小组件上下内边距，保证有效触达 |
| 7 | 溢出防护 | 为标题类元素补充 `overflow-wrap: break-word` |

**桌面端影响**：补丁为纯增量设计，桌面端渲染结果与 2.0 版一致，详见第 4 章。

### 3.4 宽屏适配

页面容器最大宽度由 1520px 提升至 1680px，于 1600px 断点生效，同时调整该断点下设置面板的栅格列宽。

该上限未放开至全宽，依据为源码中的原作者注释：1920px 全宽会使 16:9 比例图表的渲染高度达到 583px，导致版式破版。因此仅提升至 1680px，在减少两侧留白的同时保持在可读高度区间内。

### 3.5 桌面双列等高版式

1200px 以上断点下，图鉴区域由单列长页改为双列网格，分组标题跨占整行，形成分节结构。相关处理如下：

1. **行距控制**：卡片自带的 `margin-bottom` 在网格布局中不产生视觉间距，且会计入网格项尺寸，导致相邻行贴合。双列下将该属性归零，行距统一由 `row-gap: 22px` 控制。
2. **同行等高**：网格设置 `align-items: stretch`，卡片内部改用弹性列布局，说明区域以 `margin-top: auto` 吸附至卡片底部，使同一行左右两张卡片底边对齐。
3. **图文并排**：双列窄栏下说明文字被压缩的规则被定向覆盖，宽卡片恢复图文并排结构。

### 3.6 分组补位机制

为避免每个分组结束后在右列留下空缺，每组末尾卡片由脚本自动附加类名 `grp-last`，在 1200px 以上断点下跨占两列，并在卡片内部恢复图文并排布局。

实现代码位于卡片创建逻辑处：

```javascript
art.className = 'chart-card'
  + ((g && GRP[g.gi].ids[GRP[g.gi].ids.length - 1] === c.n) ? ' grp-last' : '');
```

即判定条件为「该卡片编号等于所在分组编号数组的末项」。因共 11 个分组，附加该类名的卡片共 11 张。

> **勘误说明**：原始交付说明将该机制表述为「奇数组末张卡跨两列补位」。经核验其实际作用范围为**每一组**的末尾卡片，而非仅限图表张数为奇数的分组。最终呈现效果一致，但机制描述应予修正。
