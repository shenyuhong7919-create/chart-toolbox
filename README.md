## 它解决什么问题

做汇报、写论文、备课的时候，常见的情况是：手上有数据，但不知道**该用哪种图**，
也不知道**这张图该怎么画**。这个工具箱把这两件事一起解决了。

每张图都配了三样东西：

| 配的东西 | 说明 |
|---|---|
| **真实图表** | 直接渲染出来的成图，不是示意图 |
| **数据交接说明** | 这张图需要什么形状的数据、有什么坑、数值大概怎么分布才好看 |
| **适用场景** | 按教学 / 科研 / 设计汇报三类场景分类，附"讲什么知识点该用这张图" |

## 主要特性

- **单文件、零依赖** —— 图表引擎已内联进 HTML，不联网也能用，不怕 CDN 被墙
- **双工作区** —— 「图鉴」查图 + 「创作台」直接生成汇报版面，顶部吸顶条一键切换
- **多档模式** —— 入门（浅色、结构简单）/ 进阶（深色、信息密度高）
- **20 款设计风格** —— 5 大流派 × 4 款，一键换装，版面底色、字体、图表造型与提示词同步改写
- **6 套色系** —— 30 张图表同步变色
- **1280 × 720 汇报版式** —— 每批 12 页，支持「换一批组合」
- **一键复制提示词** —— 完整档 / 精简档，配套发给 AI 继续加工
- **打印 / 导出 PDF** —— 打印时自动退回浅色，黑底白字不会打出一页墨
- **响应式** —— 520px 到 1600px 自适应，窄屏自动落单栏

## 怎么用

1. 打开任一 HTML 文件（Chrome / Edge / Safari 均可）
2. **图鉴**：挑一张图 → 对照「要交给我的数据」备好数据 → 点「一键复制」，
   把代码连同数据文件发给 AI
3. **创作台**：挑风格 → 挑版面 →「复制提示词」→ 连同数据 / 图本发给 AI
