# 30+ 数据图表工具箱

一个**单文件 HTML** 的数据图表模板工具箱。双击打开就能用，不需要安装任何东西、不需要联网。

## 它解决什么问题

做汇报、写论文、备课的时候，常见的情况是：手上有数据，但不知道**该用哪种图**，
也不知道**这张图该怎么画**。这个工具箱把这两件事一起解决了。

含 30+ 种图表模板，每种都配了三样东西：

| 配的东西 | 说明 |
|---|---|
| **真实图表** | 直接渲染出来的成图，不是示意图 |
| **数据交接说明** | 这张图需要什么形状的数据、有什么坑、数值大概怎么分布才好看 |
| **适用场景** | 按教学 / 科研 / 设计汇报三类场景分类，附"讲什么知识点该用这张图" |

## 主要特性

- **单文件、零依赖** —— 图表引擎（ECharts）已内联进 HTML，不联网也能用，不怕 CDN 被墙
- **双模式** —— 入门版（浅色、结构简单）/ 进阶版（深色、信息密度高）
- **6 套色系** —— 一键换肤，标题渐变和图表配色整套跟着变
- **4 档组件尺寸** —— 同一张图有不同尺寸的排版配置，网格留白、图例位置、标签角度都单独调过
- **三种复制方式** —— 前置指令 / 指令 + 代码 / 纯代码，方便把图丢给 AI 继续加工
- **响应式** —— 520px 到 1600px 自适应，窄屏自动落单栏
- **可打印** —— 打印时自动退回浅色，黑底白字不会打出一页墨

## 怎么用

下载 `index.html`，双击用浏览器打开即可。

## 说明

页面里的数据均为**合成示例数据**，用于演示图表的形态与适用场景，不来自任何真实业务台账。
